# Cee.Lux Studio

Website for Cee.Lux Studio. Where your crown meets Luxury.

Static site: `index.html` plus photos in `images/`. No build step.

## Editing

Open `index.html` and find the block marked `CONTENT: edit here` inside the script:

- `BOOKING_URL`: paste the booking page link and every Book Now page switches to it.
- `SERVICES`: set `price` and `time` for each style (for example `price:'£120'`, `time:'5–7 hrs'`).
- `ADDONS`, `REFS`, `FEATURED`: add-on text, twist reference photos and the styles shown on Home.

Replace a photo by overwriting its file in `images/` (same name).
